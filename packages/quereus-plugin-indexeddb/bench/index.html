IndexedDB native-index resolution benchmark

Prices resolving a secondary-index lookup's rows two ways: the plugin's current index store + one get() per row path (arm A) against an engine-maintained IDBIndex that returns whole records from one request (arm B), plus three controls. Nothing here imports the plugin or the engine — raw IndexedDB only. Results land in window.__benchResults as JSON. See README.md for what each arm does and how to read the numbers.
