# Pre-existing failure: `yarn docs:check` size ratchet

## Command

From the repo root:

```
yarn docs:check      # → node scripts/check-docs.mjs
```

(Also reached as the first step of `yarn check`. Not part of `yarn lint` or
`yarn test`, both of which pass.)

## Failure

```
docs/runtime.md: 13794 words exceeds its ratchet of 13220 (+574) — a doc may shrink, never grow
docs/schema.md: 16699 words exceeds its ratchet of 15915 (+784) — a doc may shrink, never grow
docs/sync.md: 16293 words exceeds its ratchet of 13511 (+2782) — a doc may shrink, never grow

3 documentation failure(s). See docs/doc-conventions.md.
```

Check C in `scripts/check-docs.mjs` compares each doc's word count against
`docs/.doc-budget.json`'s `ratchet` map, which is only ever lowered by
`node scripts/check-docs.mjs --update-ratchet`.

## Why this is pre-existing

The `index-names-unique-per-schema` review pass touched exactly one file,
`docs/invariants.md` (`git status --short` shows `M docs/invariants.md` and
nothing else), and `docs/invariants.md` is **not** among the three failures. The
three over-ratchet docs are `runtime.md`, `schema.md`, and `sync.md`, none of
which this ticket or its implement commit (`24371ae2`) modified — that commit's
only doc change was `docs/sql-ddl.md`, which passes.

The overflow accumulated across earlier tickets that added prose to those three
docs without lowering (or re-recording) their ratchet entries; `sync.md` is
+2782 words, far more than any single change.

## Note

Because two of the three over-ratchet docs are `schema.md` and `sync.md`, this
review deliberately did **not** add the cross-reference sentences it would
otherwise have put in them (the normative statement went into
`docs/invariants.md` as `SCH-001` instead). Any ticket that resolves this should
either trim those docs or re-record the ratchet with a stated reason, per
`docs/doc-conventions.md`.
