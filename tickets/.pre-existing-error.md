
registration is refused as a bag.

## Why these are pre-existing

Verified directly rather than inferred: with `packages/quereus/src/vtab/memory/module.ts`
temporarily replaced by its `HEAD` contents (the only file in this ticket's diff that the
in-memory query path executes), both tests fail with the same error. The working file was
restored immediately afterwards.

Independently: this ticket adds a plan-time `PredicateConstraint.runtimeSet` field plus two
shared helpers, and nothing in the planner emits a `runtimeSet` yet. Every existing filter
shape (`=`, empty/one/many-element literal `IN`, non-equality ops) routes through the new
helpers to exactly the value the inline tests produced before. The failing path is
materialized-view unique-key provability, which never consults `getBestAccessPlan`.
