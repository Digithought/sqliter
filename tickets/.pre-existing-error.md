# Pre-existing failure: `docs/schema.md` exceeds its documentation size ratchet

## Command

From the repo root:

```
yarn docs:check          # = node scripts/check-docs.mjs
```

(`docs:check` is the first step of `yarn check`.)

## Failure

```
docs/schema.md: 15825 words exceeds its ratchet of 15679 (+146) — a doc may shrink, never grow

1 documentation failure(s). See docs/doc-conventions.md.
```

The ratchet lives in `docs/.doc-budget.json` (`ratchet["docs/schema.md"] = 15679`).

## Why this is pre-existing

`docs/schema.md` is untouched by the ticket being reviewed
(`alter-primary-key-rebuild-suppress-internal-events`, which edits only
`docs/sql-ddl.md`, `docs/usage.md`, and — in the review pass — `docs/module-events.md`),
and it is unmodified in the working tree. The last commit to touch it is
`af39b5b5 ticket(implement): bug-alter-primary-key-generated-ddl-keeps-old-key`, three
commits before this one, which grew the doc without lowering it back under the ratchet or
raising the ratchet entry.

`yarn lint`, `yarn build`, `tsc -b tsconfig.build.json` and `yarn test` (full workspace
sweep) are all green; this is the only failing gate.

## Note for triage

`scripts/check-docs.mjs --update-ratchet` deliberately **refuses** to raise an entry without
`--force`, so the fix is either to trim ~150 words of `docs/schema.md` back under 15679, or to
raise the entry with `--update-ratchet --force` and justify the growth in the commit message.
Deciding which is the triage pass's call, not a mechanical bump.
